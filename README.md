## 🛠️ Technical Architecture & Ecosystem

Our system utilizes a high-efficiency serverless stack designed for lightning-fast presentation rendering and secure transaction histories:

* **Frontend Framework:** React 18, Vite, and Tailwind CSS (rapidly prototyped via Bolt.new, refactored in Cursor AI).
* **Intelligence Layer:** Claude 3.5 Sonnet prompt injections engineered to filter definitions through regional tech ecosystem analogies.
* **Database & Security Edge:** Supabase PostgreSQL running strict, role-scoped Row Level Security (RLS) models.

## 🔐 Database Security Implementation (Idempotent Ledger)

We applied advanced, role-scoped database permissions inside Supabase to securely isolate student metrics:

* **Zero Anonymous Vulnerability:** Completely revoked public client `anon` access parameters on the storage grid.
* **Explicit Role Scoping:** Bound data writes strictly to verified `authenticated` developer tokens using an isolated `auth.uid() = user_id` lookup validation.
